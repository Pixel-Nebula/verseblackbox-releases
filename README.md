# Verse Blackbox — Downloads

Star Citizen companion for the Corsair Xeneon Edge.
Star-Citizen-Begleiter für das Corsair Xeneon Edge.

The guide is included / Die Anleitung liegt bei.

The companion reads Star Citizen's Game.log on your PC. It does not modify
game files and does not interfere with the game.
Der Companion liest die Game.log deines Spiels. Er verändert keine
Spieldateien und greift nicht ins Spiel ein.
